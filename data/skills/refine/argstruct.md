# Skill: argument structure

With the senses settled, check the core roles against each frame.

- `:ARG0` is the prototypical agent, `:ARG1` the prototypical patient; the
  frame decides, not word order.
- Move a participant to a non-core role (`:manner`, `:purpose`, `:temporal`,
  `:location`) when it is not an argument of the frame at all.
- Add participants the draft dropped; remove ones it invented.

Do not touch `:aspect` or entity structure here.
